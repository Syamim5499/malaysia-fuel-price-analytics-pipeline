Data definitions and analysis notes

Source: the official data.gov.my fuel-price catalogue, using its price-level series. Values are in Malaysian ringgit per litre. Dates are the published effective dates.

Categories: RON95 and RON97 are the catalogue’s standard series. BUDI95, SKPS, BUDI diesel and SKDS are shown separately. Scheme eligibility and allowances are outside this dashboard.

Calculations: price movement compares the latest observed value with the preceding available value for that category. Monthly averages use only observations in the chosen date range. The diesel gap requires both regional values on the same date. Missing values stay missing.

Freshness: the dashboard includes a saved official-data snapshot and attempts a fresh API request when opened. If that request fails, the saved data remains available with its effective date clearly shown. Chart zoom changes the visible chart window; date filters determine the KPI, monthly and table calculations.

Project: this browser dashboard reads the official API. The source repository separately demonstrates an Airflow, PostgreSQL and Streamlit pipeline.
